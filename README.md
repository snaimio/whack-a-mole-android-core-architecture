## 📌 Technical Overview

**Whack-A-Mole** is a native Android reflex game engineered with Kotlin. It demonstrates decoupled game loop architecture, randomized mole pop-up intervals, touch collision detection, streak score multipliers, and activity lifecycle pause/resume handling.

---

## ✨ Key Features

- **Dynamic Spawn & Timing Loops**: Randomized spawn intervals with progressive difficulty acceleration.
- **Accurate Touch Hitbox Detection**: Instantaneous tap registration with visual feedback animations.
- **Streak & High Score Persistence**: Local high score ledger with game-over summaries.
